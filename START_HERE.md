## 🚀 QUICK START (6 minutes to live)

### 1. Test Locally (2 min)
```bash
npm install
npm run dev
# Visit http://localhost:5173
# Test: register → login → create job → send message
```

### 2. Push to GitHub (2 min)
```bash
git init
git add .
git commit -m "ProNet MVP - Production Ready"
git remote add origin https://github.com/YOUR_USERNAME/professional-network
git push -u origin main
```

### 3. Deploy to Netlify (2 min)
- Go to app.netlify.com → New site from Git
- Select your repository
- Build: `npm run build`
- Publish: `dist`
- Add environment variable: `JWT_SECRET=your-secure-string`
- Deploy!

**Result**: Your app is live at `https://your-site-name.netlify.app` ✨
